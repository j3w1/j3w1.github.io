# j3w1.github.io

Personal site for 申杰 / j3w1 — software, writing, projects, and developer tooling.

GitHub Pages publishes the site from the root of `main` at <https://j3w1.github.io/>.

## Local preview

From the repository root:

```sh
python -m http.server 8000
```

Then open <http://localhost:8000/>.

The site is dependency-free: semantic HTML, modern CSS, and no build step.
