申杰 / j3w1

Writer · Software Engineer

I work on software that has to survive contact with real organizations: business systems, operational workflows, and the tools engineers use to build and maintain them.

My interests connect software architecture with writing and developer environments. I care about clear boundaries, recoverable workflows, evidence that can be checked, and systems that remain understandable after the original implementation context is gone.

Current work includes CE Systems, an internal operations platform for Casa Elida, and CE-GD, a private engineering-governance effort around bounded AI-assisted review and delivery control.

Public work includes Bloody Writer, a maintained Arch Linux workspace for WSL and Termux, and 1688toCSV, a focused browser extension for practical order-data export.
